# Nikito-Shit

Android boot animation assets.

## Tux boot animation

- Display: 720 × 405
- Frame rate: 15 FPS
- Duration: 30 seconds (150 unique frames, repeated 3 times)
- Layout: dim readable C code on the left for LiveBoot/logcat visibility; spinning Tux on the right

The installable artifact is `bootanimation.zip`.

curl -k -L -A "Mozilla/5.0" -o bootanimation.zip "https://limewire.com/decrypt/download?downloadId=40b2f1ca-d184-4056-8930-793d3a0e430d"
